###

to use the config
1. install the programm stow
z.b. with dnf
```
sudo dnf install stow
```

2. clone this repo
```
git clone https://github.com/NEXT876/dotfiles/
cd dotfiles
```

3. use stow on the config u wanna need to add the symlink
z.b. kitty
```
stow kitty
```
